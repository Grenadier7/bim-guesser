# 03 – Ideen (gesammelt in Phase 2, keine Fehler)

- **Tägliche Strecke**: eine Routenjagd-Runde pro Tag, für alle gleich – teilbares Ergebnis („3 min langsamer als optimal“).
- **Netzänderungen sichtbar machen**: „Was ist anders als im regulären Netz?“ (Sperren, Ersatzbusse) als eigene Lernkarte.
- **Gemerkte Strecken aus dem Training in Routenjagd-Runden** einstreuen (Wiederholung mit Punkten).
- **Fortschritt pro Bezirk**: Karte, welche Bezirke man in Quiz/Training schon gut kennt.
- **Linienfarben-Modus**: Bim/Bus optional in Einzelfarben statt Verkehrsmittel-Farbe (Netzkarte).
- **Offline-Lernen** (Service Worker) – Lernen und Quiz allein brauchen keinen Server außer den Netzdaten.
- **Statistik für den Host**: welche Stationen/Linien die Gruppe am häufigsten falsch hat.
- **Linter (ESLint) + Formatter** im Release-Skript (siehe 01-struktur.md).
